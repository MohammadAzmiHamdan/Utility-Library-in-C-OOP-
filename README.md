🚀 **Project 10 — Building a Utility Library in C++ (OOP)**

I’m excited to share **Project 10** from the **Programming Advices roadmap by Dr. Mohammed Abu-Hadhoud**.

In this project, I built a reusable **Utility Library in C++** designed to collect and organize many commonly used programming functions in one place.

The main goal was not simply to write individual functions, but to build a library that can be reused across different projects and reduce repeated code.

🧩 **What does the Utility Library contain?**

🔹 **Randomization Utilities**

* Generate random numbers within a specific range
* Generate random characters
* Generate random words
* Generate random keys
* Generate multiple keys
* Random Boolean values
* Dice rolling

🔹 **Number Utilities**

* Check whether a number is Even or Odd
* Check whether a number is Prime
* Calculate Factorial
* Check Perfect Numbers
* Reverse numbers
* Calculate the sum of digits
* Check Palindrome numbers
* Check divisibility

🔹 **Swap Functions**
I implemented overloaded `Swap()` functions to work with different data types, including:

* `int`
* `double`
* `bool`
* `char`
* `string`
* `clsDate`

This helped me practice **Function Overloading** and understand how the same function name can provide different implementations depending on the data type.

🔹 **Mathematical Utilities**
The library also contains custom implementations for several mathematical operations, such as:

* Absolute Value
* Fraction Part
* Round
* Floor
* Ceiling
* Square Root

🔹 **Array Utilities**
A large part of the project focuses on working with arrays, including:

* Reading and printing arrays
* Filling arrays with random numbers
* Finding maximum and minimum values
* Calculating the sum and average
* Copying arrays
* Reversing arrays
* Shuffling arrays
* Searching for numbers
* Checking whether a number exists
* Adding elements
* Copying Odd numbers
* Copying Prime numbers
* Copying Distinct numbers
* Counting Odd, Even, Positive and Negative numbers
* Checking whether an array is a Palindrome
* Generating arrays with sequential values
* Working with arrays of generated keys

🔹 **Number to Text**
One of the interesting parts of the project was implementing a function that converts numbers into **English words**, supporting numbers from smaller values up to large numbers involving thousands, millions, and billions.

🔐 **Encryption & Decryption**

I also implemented simple **text encryption and decryption** using a character-shifting technique.

This gave me practical experience with manipulating strings character by character and understanding the basic idea behind reversible transformations.

💡 **What I learned from this project**

This project helped me strengthen several important C++ concepts:

✅ Object-Oriented Programming
✅ Classes and Static Functions
✅ Function Overloading
✅ Working with Arrays
✅ Strings and Character Manipulation
✅ Random Number Generation
✅ Algorithms and Problem Solving
✅ Code Reusability
✅ Organizing Utility Functions
✅ Building reusable components for future projects

More importantly, I started thinking beyond **“How can I solve this problem?”** and more about:

> **“How can I write this solution once and reuse it in many future projects?”**

This project is another step toward writing more **organized, reusable, and maintainable C++ code**.
